# design-explorations

トップページの UI を作り直すための候補を、本番のコードとは切り離して並べたもの。ビルド・デプロイの対象外。

`index.html` をブラウザで開くと、10 案を「1 案ずつ / 一覧」「デスクトップ / スマホ幅」「ライト / ダーク」で切り替えて比べられる。各案は `candidates/` に 1 ファイルずつあり、単体でも開ける。09・10 は損失曲面と軌跡の計算を `candidates/descent-core.js` で共有している。

| #   | 案         | 着想                                                 | 主なライブラリ    |
| --- | ---------- | ---------------------------------------------------- | ----------------- |
| 01  | 勾配降下   | 等高線図の上を、スクロール量に合わせて SGD の点が降りる | d3-contour        |
| 02  | 損失曲面   | 3D の損失曲面を玉がモメンタム SGD で転がる            | three.js          |
| 03  | 論文       | プロフィールを 1 本のプレプリントとして組む           | MathJax           |
| 04  | 学習ログ   | 学習ジョブのターミナル出力として組む                  | なし              |
| 05  | 探索木     | サイト全体を探索木にし、スクロール位置までの経路を色付け | d3-hierarchy      |
| 06  | ポスター   | 経歴の文脈から離れた、巨大な明朝の文字組み            | なし              |
| 07  | 縦組み     | 本文を縦組みで右から左へ読む紙面                      | なし              |
| 08  | 焼きなまし | 巡回セールスマン問題を焼きなまし法で解く様子を冒頭に   | なし              |
| 09  | 降下経路   | 01 × 05。等高線図を目次にし、セクションを通過点に置く   | d3-contour        |
| 10  | 降下ログ   | 01 × 04。地形 + 損失曲線を固定し、本文を学習ログに      | d3-contour        |

- 表示内容は `src/data/profile.ts` / `src/data/projects.ts` を `candidates/profile-data.js` に写したもの。公開記事は 0 件なので、記事欄は空の状態で出している。
- ライブラリと Web フォントは CDN(cdnjs / jsDelivr / Google Fonts)から読むので、オフラインでは代替フォント・描画なしになる。
- 採用する案が決まったら、Astro のコンポーネントとして作り直す(ここのファイルは本番に持ち込まない)。
